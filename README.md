# Auroa for Apple TV

Auroa is a free media app for Apple TV, with profiles, themes and support for the accounts you already have.

Website: https://auroa.uk
Support: support@auroa.uk

## Download

Get the latest unsigned `.ipa` from the [Releases](../../releases/latest) page.

## Install

Auroa is not on the App Store. You sign the file with your own Apple ID and install it on your Apple TV with Xcode.

1. Download the `.ipa`.
2. Sign it with your Apple ID.
3. Install it on your Apple TV with Xcode or any sideloading application.
4. Open Auroa and create a profile.

A free Apple ID signs an app for 7 days, so you will need to sign it again each week. A paid developer account lasts a year.

## Notes

Auroa does not host any media. It uses the TMDB API but is not endorsed by TMDB. Not affiliated with Apple. See the terms, privacy and DMCA information at https://auroa.uk/legal.html.
